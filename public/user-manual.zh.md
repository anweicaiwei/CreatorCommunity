## 1. 项目与页面结构

`CreatorCommunity` 是一个 Web3 前端应用，用来体验“创作获得奖励，再用奖励铸造 NFT 徽章提升收益”的流程。

### 页面入口

- 首页：`/CreatorCommunity/`
- 手册页（自动跳转当前语言）：`/CreatorCommunity/manual`
- 中文手册：`/CreatorCommunity/manual-zh`
- 英文手册：`/CreatorCommunity/manual-en`

### 首页功能区

你在首页会看到这些区域：

1. 钱包与合约状态
   - 连接钱包
   - 校验网络
   - 查看当前地址、区块浏览器链接、连接时长
   - 部署或查看当前链上的 CTK / NFT 合约地址
2. 奖励区
   - 领取初始奖励
   - 提现发帖奖励、评论奖励、初始奖励或全部待领取奖励
   - 在管理员开启转账功能后执行 CTK 转账
3. 帖子互动区
   - 发帖奖励
   - 查看帖子列表
   - 选择帖子执行评论奖励
4. NFT 区
   - 铸造 Bronze / Silver / Gold NFT
   - 销毁 NFT 退款
   - 在管理员开启转账功能后转移 NFT
5. 管理员区
   - 查看奖池和 NFT 合约余额
   - 发放奖励
   - 调整 NFT 价格
   - 提取 NFT 合约中的 CTK
6. 右侧栏
   - 链上数据概览
   - 交易历史

## 2. 快速开始

### 2.1 准备环境

使用前需要：

- 安装 MetaMask 或兼容 `window.ethereum` 的钱包
- 切换到 Sepolia 测试网
- 准备少量 Sepolia 测试 ETH 作为 gas

默认网络配置如下：

- Chain ID：`11155111`
- 网络名：`Sepolia Testnet`
- RPC：`https://ethereum-sepolia-rpc.publicnode.com`
- 浏览器：`https://sepolia.etherscan.io`

### 2.2 连接钱包

1. 打开首页
2. 点击“连接钱包”
3. 在 MetaMask 中确认授权
4. 连接成功后，页面会显示：
   - 钱包地址
   - 当前网络
   - 是否已部署合约
   - 区块浏览器地址链接

如果当前网络不是目标网络，页面会提示切换网络。

### 2.3 首次部署或恢复地址

当前应用不预置合约地址。首次使用某条链时，需要先部署。

1. 连接钱包后，查看“合约状态”
2. 如果显示未部署，点击部署按钮
3. 前端会部署 `CreatorToken`
4. 部署成功后，前端会自动读取 `creatorNFT()` 并保存 NFT 合约地址
5. 刷新页面后，会从本地恢复这两个地址

说明：

- 地址是按链保存的
- 切换到另一条链时，如果该链没有保存过地址，会重新显示为“未部署”
- 断开钱包不会清掉已保存地址

### 2.4 建议的首次体验顺序

建议按这个顺序体验完整流程：

1. 连接钱包并确认网络正确
2. 部署合约或恢复已有地址
3. 领取初始奖励
4. 提现初始奖励，让 CTK 进入钱包余额
5. 执行一次发帖奖励
6. 在帖子列表里执行评论奖励
7. 提现待领取奖励
8. 累积足够 CTK 后铸造 NFT

## 3. 功能使用说明

### 3.1 链上数据面板

右侧链上数据面板会显示：

- CTK 余额
- 初始奖励是否已领取
- 发帖冷却
- 评论冷却
- NFT 总增益
- Bronze / Silver / Gold 当前价格
- NFT 总持有数量
- 各档 NFT 持有数量
- 各类待领取奖励

点击刷新后会重新读取链上数据。  
如果本地有缓存，页面会先显示缓存，再在需要时补刷新。

### 3.2 初始奖励

每个地址只允许领取一次初始奖励。

操作步骤：

1. 点击“领取初始奖励”
2. 在钱包中确认交易
3. 成功后，奖励会进入“待领取初始奖励”

重要：

- 这一步只是记账，不是直接到账
- 想让 CTK 进入钱包余额，还要继续点击“提现初始奖励”

### 3.3 发帖奖励

操作步骤：

1. 点击“发帖奖励”
2. 在钱包中确认交易
3. 成功后，系统会记录一个新的帖子 ID
4. 相应奖励进入“待领取发帖奖励”

你需要知道的行为：

- 发帖奖励有 5 分钟冷却
- 冷却结束前不能继续领取发帖奖励
- 页面会显示倒计时
- 倒计时会写入本地缓存，刷新页面后会继续恢复显示

### 3.4 评论奖励

帖子列表来自链上 `postIdCounter` 和 `postAuthor` 数据。

操作方式：

1. 打开帖子列表
2. 选择一个帖子
3. 点击该帖子旁边的评论奖励按钮
4. 在钱包中确认交易

评论奖励的特点：

- 评论者和帖子作者都会获得奖励记录
- 奖励先进入待领取，不是直接转进钱包
- 评论奖励有 30 秒冷却

### 3.5 奖励提现

奖励区提供四类提现操作：

- 提现发帖奖励
- 提现评论奖励
- 提现初始奖励
- 一次性提现全部奖励

这里是本项目最容易误解的地方：

- `claimInitialReward`、`rewardPost`、`rewardComment` 只是在链上记录待领取奖励
- 只有执行对应 `withdraw*` 交易，CTK 才会进入你的钱包余额

如果你已经“拿到奖励”但 CTK 余额没有变化，先检查待领取奖励字段，再执行提现。

### 3.6 CTK 转账

CTK 转账不是默认永久可用。

只有当管理员在页面上打开“转账功能”后，奖励区才会出现 CTK 转账表单。  
如果你看不到 CTK 转账入口，不一定是异常，通常只是当前未开启。

### 3.7 NFT 铸造

应用支持三档 NFT：

- Bronze
- Silver
- Gold

铸造前，前端会先检查你当前的 CTK 余额是否足够。  
每次铸造成功后，页面会刷新：

- CTK 余额
- NFT 数量
- NFT 增益
- 你持有的各档 NFT 列表

NFT 增益规则：

- Bronze：每枚 `0.5%`
- Silver：每枚 `2%`
- Gold：每枚 `12%`

前端会同时展示：

- 理论增益总和
- 合约实际返回的 NFT 增益

### 3.8 NFT 销毁退款

你可以在自己持有的 NFT 列表里直接销毁某一枚 NFT。

前端会先校验：

- 该 NFT 是否存在
- 当前地址是否为该 NFT 的 owner

销毁后：

- NFT 被移除
- 按合约规则退还铸造价格的 80%
- 页面会刷新 NFT 数量、增益和 CTK 余额

### 3.9 NFT 转移

NFT 转移入口和 CTK 转账一样，也受管理员开关控制。  
只有在转账功能开启时，NFT 模块底部才会显示转移表单。

操作时需要输入：

- 接收地址
- NFT Token ID

### 3.10 交易历史

每次通过页面发起的写交易，都会写入本地交易历史，包括：

- 交易类型
- 交易哈希
- 时间
- 区块浏览器链接

交易历史是本地缓存，不是链上索引结果。  
清空历史只会清空本地记录，不会影响链上交易本身。

## 4. 管理员工作流

只有 `CreatorToken.owner()` 等于当前钱包地址时，管理员区才会显示。

管理员可执行的前端操作包括：

### 4.1 奖池查询

可查看：

- 创作者池余额 / 总额
- 互动池余额 / 总额
- NFT 池余额 / 总额
- NFT 合约当前 CTK 余额
- 可提取 CTK
- 溢出 CTK

### 4.2 发放奖励

管理员可以：

- 从创作者池向任意地址发奖
- 从互动池向任意地址发奖

当前前端没有接入批量发奖入口，即使合约中存在 `batchSendReward`。

### 4.3 NFT 价格管理

管理员可以执行：

- 重置 NFT 价格
- 随机调整 NFT 价格

价格调整影响的是之后的铸造与退款逻辑，不会改变已持有 NFT 的身份归属。

### 4.4 提取 NFT 合约中的 CTK

管理员可以执行三种提取操作：

- 提取指定数量 CTK
- 提取全部可提取 CTK
- 提取溢出 CTK

当前前端没有接入：

- `CreatorToken.withdrawTokens`
- `CreatorToken.destroyContract`
- `CreatorNFT.recoverCTK`

这些方法存在于合约中，但不是当前 UI 的一部分。

### 4.5 转账功能开关

管理员可以切换“转账功能”开关。

开关影响普通用户能否看到：

- CTK 转账入口
- NFT 转移入口

这只是前端可见性控制，不会改变合约本身的标准转账能力。

## 5. 数据、缓存与限制

### 5.1 本地缓存

应用会把多类数据保存在 `localStorage`：

- 合约地址
- 当前链
- 用户链上数据快照
- 奖池数据
- 帖子列表
- 交易历史
- 转账功能开关状态
- 暗色模式设置
- 发帖 / 评论冷却结束时间

### 5.2 地址与缓存按链隔离

当前实现会按链和合约地址隔离缓存。  
简单理解就是：

- 不同链上的地址记录互不影响
- 不同链上的用户数据缓存互不影响
- 同一链、同一合约下，不同钱包地址的数据也分别存放

### 5.3 冷却时间恢复

发帖和评论冷却时间会单独缓存。  
如果你刷新页面，倒计时不会从头开始，而是会根据缓存继续恢复。

### 5.4 断开钱包不等于清空部署

点击断开钱包后：

- 会清掉当前页面里的用户态数据
- 不会删除当前链上保存过的合约地址

这意味着你重新连接同一条链时，前端仍然可以恢复之前部署过的地址。

### 5.5 你可能会注意到的限制

- 转账入口默认可能不可见
- 某些合约方法存在，但前端没有做按钮
- 帖子列表展示的是链上记录的帖子 ID 和作者，不包含正文内容
- 交易历史只记录通过当前页面发起的写交易

## 6. FAQ

### 1. 我明明已经点击“领取奖励”，为什么 CTK 余额没变？

因为奖励流程分两步：

1. 先记录待领取奖励
2. 再执行提现，把 CTK 真正转入钱包

### 2. 为什么我看不到 CTK 转账或 NFT 转移入口？

因为这两个入口受管理员的“转账功能”开关控制。  
当前没显示，通常表示未开启。

### 3. 刷新页面后为什么还能看到之前的合约地址？

因为合约地址按链保存在本地缓存里。  
刷新不会清除它们，断开钱包也不会清除它们。

### 4. 切换网络后为什么突然显示未部署？

因为合约地址是按链保存的。  
新链上如果没有保存过地址，前端就会把它视为新的部署环境。

### 5. 为什么帖子列表里只有帖子 ID 和作者？

因为当前前端只读取了链上能直接查询到的帖子编号和作者地址，并没有帖子正文存储逻辑。

### 6. 管理员和普通用户看到的是两个页面吗？

不是。  
两者使用同一个首页，只是当当前地址被识别为 owner 时，会额外显示管理员区域和部分控制入口。
